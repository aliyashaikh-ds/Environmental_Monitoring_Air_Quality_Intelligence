# 🌍 Environmental Monitoring: Air Quality Intelligence

## Project Overview

Environmental Monitoring: Air Quality Intelligence is a team project focused on analyzing air pollution patterns across Indian cities using data analysis, visualization, and machine learning.

The project combines air-quality data, weather information, and geographical details to understand pollution trends, identify highly polluted regions, estimate the Air Quality Index (AQI), and explore future AQI forecasting.

## 🎯 Project Objectives

- Analyze air pollution levels across different Indian cities and regions.
- Identify pollution hotspots using AQI and PM2.5 measurements.
- Study relationships between air pollutants and weather conditions.
- Develop machine learning models for AQI estimation and forecasting.
- Visualize geographical pollution patterns through interactive maps.
- Generate rule-based alerts to communicate air-quality conditions.

## 📊 Datasets Used

The project uses three datasets:

| Dataset | Description |
|---|---|
| `cities.csv` | City details, state, region, latitude, longitude and elevation |
| `air_quality_daily.csv` | Daily AQI and pollutant measurements |
| `weather_daily.csv` | Temperature, humidity, wind speed and precipitation data |

After data cleaning and integration, the final dataset contains **77,150 rows and 39 columns**.

## ⚙️ Project Workflow

1. **Data Loading:** Import the required datasets using Pandas.
2. **Data Preprocessing:** Clean the data, convert date columns and handle dataset integration.
3. **Data Integration:** Merge air-quality, weather and city information.
4. **Feature Engineering:** Extract year, month and day of the week.
5. **Exploratory Data Analysis:** Study regional AQI, city-level pollution and monthly trends.
6. **Data Visualization:** Generate correlation heatmaps, trend charts and geographical visualizations.
7. **AQI Estimation:** Train a Random Forest Regression model.
8. **AQI Forecasting:** Create lag features and rolling averages for time-series forecasting.
9. **Decision Support:** Generate city-level air-quality alerts using predefined threshold rules.

## 📈 Machine Learning Models

### 1. AQI Estimation

Algorithm: Random Forest Regressor

- Number of trees: 100
- Train-test split: 80:20
- Evaluation metrics:
  - R² Score: **0.8976**
  - Mean Absolute Error (MAE): **14.79**

### 2. Time-Series AQI Forecasting

A second Random Forest model is used for forecasting with time-based features.

Features include:
- Previous AQI values (1, 2 and 3 days).
- Seven-day rolling averages of AQI and PM2.5.
- City-wise chronological data.

Evaluation results:
- RMSE: **23.41**
- R² Score: **0.8178**

## 🚨 Air Quality Alert System

The project includes a rule-based alert mechanism for selected cities.

The alert conditions include:

- AQI above 300: Severe health-hazard message.
- AQI above 200: Poor air-quality warning for sensitive individuals.
- Wind speed below 8 km/h: Stagnant-wind warning.
- Rainfall above 10 mm: Rain advisory.

These are project-defined illustrative thresholds and are not official government or medical advisories.


6. Run all cells sequentially to execute the project.
